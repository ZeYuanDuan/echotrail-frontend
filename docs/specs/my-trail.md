# My Trail 已確認事件

My Trail 進入 `/trail` 時呼叫 `GET /api/events?userId=<uuid>`，顯示該使用者的全部已確認 Echo Card。未確認的預覽不會出現；卡片確認成功後，即使後續 Dashboard 自動重算失敗，也能在重新載入後看到。

後端按資料庫 `created_at ASC, id ASC` 排序。前端完整保留 API 順序，以事件 UUID 作為元件 key，建立時間只用於顯示。同一天的多筆事件各自保留；不使用事件敘述推算日期，也不顯示寫死的季度或種子事件。

有多筆事件時，以垂直時間節點顯示日期、時間與標題，預設選取最新一筆，不使用橫向拖移。寬度超過 1100px 的桌面版在左側顯示可持續向下延伸的事件索引，右側顯示單張 Echo Card；1100px 以下的平板與手機版則將卡片直接展開在所選節點下方。點擊其他節點會切換事件，再次點擊目前節點會收合卡片。

無事件時顯示「還沒有留下事件」並引導開始對話。API 失敗時顯示重試。切換使用者會先清空舊清單，舊使用者延遲完成的 GET 不能改寫新使用者畫面。

My Trail 不提供手動更新 Dashboard 的操作；Dashboard 由確認 Echo Card 後的自動重算流程更新。
