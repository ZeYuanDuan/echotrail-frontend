# My Trail 版本範圍

## V1：預設顯示

進入 `/trail` 只顯示頁首與「事件 6：主管報告雙標對待（7/2）」的完整 Echo Card 詳情，包括事件、情緒、在意與擅長、不適合、價值主張與 Dashboard 關聯。
即使本機已有新增事件，預設仍顯示事件 6。

## V2：可展開的假資料預覽

- 年份與季度選擇
- 季度標示、共鳴次數、本季的我與心情摘要
- 事件時間軸／選擇清單
- 回顧／重新討論按鈕
- 其他季度與事件詳情、空資料狀態

## 操作與顯示

右上角「查看 V2 假資料」展開原本完整的 My Trail 互動介面，初始選中事件 6，可切換季度與事件，也可重新討論。點「收起 V2 假資料」後回到只顯示事件 6；再次展開保留本次頁面的季度與選取狀態。

開關使用 My Trail 元件內獨立的 `ref(false)`，不與 Dashboard 共用，不寫入 localStorage。重新整理或離開再進入預設收起；不改動已儲存事件或對話。Dashboard 開關僅控制 Dashboard。

沿用共用 Button，包含 `aria-expanded` 與 `aria-controls`，支援鍵盤操作及窄版換行。
