## 操作與顯示

進入 `/dashboard` 預設只顯示 V1。右上角「查看 V2 假資料」按鈕展開頁面下方的 V2 預覽；按鈕改為「收起 V2 假資料」，可再次收起。展開期間 V1 持續顯示。

展開狀態只保留於本次頁面，不寫入本機儲存；重新整理或離開後再進入會恢復收起。切換不會更動對話、Echo Card、已儲存事件或分析更新狀態。原本 Dashboard 假資料與更新標記保留，V2 作為後續開發參考。

按鈕使用共用 Button，提供 `aria-expanded` 與 `aria-controls`，支援鍵盤操作；窄螢幕時頁首自動換行，避免水平溢出。
