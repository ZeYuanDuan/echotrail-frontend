# Dashboard 對話訊號預覽

## V1 優先內容

Dashboard 首頁是所有主要洞察的總覽，優先呈現五項內容：

1. 我的 Persona：人物輪廓、具體摘要與代表原句。
2. 我的共鳴之錨：聚合所有已分析事件的 LLM 結果，在三個圓內呈現能力基礎、動機基礎、價值基礎及其交集。
3. 重複關鍵字排行榜：依累積權重調整字級。
4. 行為模式排行榜：由事件整理出的反覆判斷與行動，保留原句證據。
5. 找到我的職場北極星：總覽與子頁都呈現八個職涯錨定名稱、聚合分數、核心追求、底線與下一步方向。

五項內容各有可直接進入的子頁，並列在 My Dashboard 下方的左側導覽。總覽中的每個區塊本身也可點擊前往子頁。

RIASEC、DISC 與訊號版職涯錨點保留在次要的「分析框架」子頁。頁面明示這些是對話推論預覽、不是正式心理測驗。

## 資料來源

使用者完成 Gemini 對話並產生 Echo Card 時，backend 同步回傳 Dashboard profile 與零到多筆框架訊號。Dashboard profile 包含 Persona、共鳴之錨三個基礎、關鍵字、行為模式及職場北極星。Persona 代表句與行為模式證據都必須是使用者逐字原句。

框架訊號包含：

- `framework`：`riasec`、`disc` 或 `schein`
- `dimension`：框架允許的維度
- `strength`：1–10 整數
- `evidenceQuote`：使用者逐字原句

找不到證據的維度不產生訊號，不為了填滿圖表硬湊；八軸圖仍列出完整八個維度，沒有 grounded 訊號者顯示 0 分。每筆事件與訊號儲存在瀏覽器狀態，更新採 INSERT-only；本版本尚未串接帳號與雲端資料庫。

## 聚合與顯示

每個維度取所有訊號 `strength` 的平均值，再乘以 10 顯示為 0–100。這是工程驗證版暫定公式，後續可替換，不宣稱為標準化測評。

- RIASEC：R／I／A／S／E／C 六條橫向長條。
- DISC：D／I／S／C 長條與象限位置。水平位置由 D 相對 S 推導，垂直位置由 C 相對 I 推導。
- Schein：八個職涯錨點長條。
- 少於三筆 grounded 事件仍顯示前置預覽，並標示目前筆數；達三筆後才適合作趨勢解讀。

右側「分數從哪裡來」依目前框架列出維度、訊號強度、逐字原句與事件標題。框架沒有訊號時顯示「沒有足夠原句，因此沒有硬湊分數」。

## 狀態

- 無已分析事件：引導返回對話。
- 有新事件：頁首顯示最新 Echo Card 的價值主張、核心原句與新增訊號數。
- RIASEC／DISC／職涯錨點可用鍵盤操作的按鈕切換。
- 桌面採圖表與證據帳本雙欄；窄螢幕改為單欄，不水平溢出。
