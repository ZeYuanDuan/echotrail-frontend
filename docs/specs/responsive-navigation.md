# 響應式導覽

寬度高於 680px 時，側邊欄底部直接顯示當前使用者名稱與「切換使用者」動作。

寬度 680px 以下時，使用者資訊收納在頂列最右側的齒輪按鈕。選單預設關閉，點擊齒輪後才顯示使用者名稱與「切換使用者」按鈕；點擊選單外或按 `Escape` 會關閉選單。切換使用者後回到首頁的暱稱輸入畫面。

手機頂列的「＋ New」保留原本中性米色實心樣式，作為切換回對話頁的導覽連結，不清除已送出的訊息或尚未送出的輸入。My Trail 與 Dashboard 當前分頁仍使用原本淡藍底、藍字與底部藍色指示線。

對話頁右上角提供「＋ 與艾可聊天」按鈕。已有對話或輸入文字時，以頁面內的 modal 確認是否開啟新聊天；取消時保留原內容，確認後才清空。沒有對話與輸入文字時直接開啟新聊天，不顯示確認 modal。

手機版的歡迎標題靠左顯示，「＋ 與艾可聊天」位於標題下方並靠右對齊。

Dashboard 子分頁選單在手機寬度下採多列自動換行，不使用橫向捲動或顯示 X 軸捲軸。項目增加時可增加頂列高度，由頁面的垂直捲動處理。
